# 守护进程和界面分成两个进程

后端进程是持有它的进程的子进程：宿主一退出，后端进程会跑完当前回合就退出，等宿主回答的审批全部失败；GPUI 组件库里还有会直接终止进程的已知缺陷（longbridge/gpui-kit#2589），一跑一小时的 Workflow 不能跟着界面一起死。所以全部会话和后端进程由守护进程持有（systemd --user 托管），桌面界面经本地 socket 连上去，将来的手机界面也连同一个守护进程。

## Consequences

守护进程和界面之间的协议从一开始按网络协议设计（消息自描述、带版本号、能断线重连），以后经 Tailscale 远程使用只换传输层。
- v1 只开本机 socket；其他电脑 v1.1、手机 v2 再开，远程只走 Tailscale 加设备配对（ADR 0014）。
- 界面冷启动一律先取快照，再接事件流（research/round10/COMPONENTS.md §8.2）。
